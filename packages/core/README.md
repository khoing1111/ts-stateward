# @stateward/core

The engine of [stateward](https://github.com/khoing1111/ts-stateward#readme) and the API for
writing rules: `defineRule`, `definePlugin`, `option`, and test helpers in
`@stateward/core/testing`. `stateward` installs it; add it yourself only to write a rule.

```bash
npm install --save-dev @stateward/core
```

How to write, load and test a rule:
[docs/user/write-your-own-rule.md](https://github.com/khoing1111/ts-stateward/blob/main/docs/user/write-your-own-rule.md).
