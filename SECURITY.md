# Security

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue. On the
[repository](https://github.com/khoing1111/ts-stateward), open the Security tab and choose "Report a
vulnerability" (GitHub's private vulnerability reporting).

Include:

- what the problem is and what it lets someone do;
- the stateward version (`npx stateward --version`), your Node version and your operating system;
- the steps or the smallest code that shows it.

## Supported versions

The latest 1.x release receives security fixes.
